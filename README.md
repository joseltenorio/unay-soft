# UnaySoft

UnaySoft es una plataforma web orientada a la gestión inteligente de restaurantes. El proyecto busca centralizar procesos como solicitud de cuenta, gestión operativa, acceso a información del negocio y solicitud de demo comercial.

## Estado del proyecto

Proyecto en desarrollo.

Actualmente se está trabajando en la estructura inicial del frontend, separación de componentes, organización de estilos y preparación de la arquitectura base para futuras páginas como Login y Dashboard.
